# FAQ Full Text Search 🔍

**This project contains a sample ASP.NET Core app. This app is an example of the article I produced for the Telerik Blog (telerik.com/blogs)**

This repository contains the code for a basic ASP.NET Core application that demonstrates the use of the Full Text Search (FTS).

---

## ✨ Features Overview

- **Full Text Search**
- **tsvector**
- **tsquery**
- **GIN indexes**
- **Relevance ranking**
- **Less efficient methods like EF Core Contains**
